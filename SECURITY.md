# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any script in this repository (for example, a script that leaks data, has an injection bug, or could be weaponized against the operator), please **do not open a public issue**.

Instead, report it privately:

- Email: **285900227+Sreevasamr@users.noreply.github.com**
- Subject: `red-team-arsenal`

Please include:
- The script and file path affected
- A clear description of the issue
- Steps to reproduce
- Any suggested fix

You will receive an acknowledgment within 72 hours. Confirmed issues will be patched and disclosed in the release notes.

## Scope

This policy covers bugs **within the scripts themselves** — not vulnerabilities in third-party targets discovered using them. For target-side vulnerabilities, follow that vendor's responsible disclosure process.
